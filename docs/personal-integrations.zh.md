## Purge Community

运行包固定安装 kingcharleslzy-ai/dsh-purge 的 MIT 许可版本 1.6.84，保留原始包、
提示词注入、预设、网页面板、状态检查和回滚入口；发行地址与 npm integrity 均固定。
在 Go 切换到官方网页版后使用 Purge 面板，网页插件发现也会列出这个包。
Android 本机引擎会自动注册「红队模式」和「无限制模式」，新建聊天时可从原生预设列表选择。
红队工具从 APK 内的运行时定位，升级后已有的红队预设也能找到工具。
新安装可直接开始红队对话。各技能仍会检查所需的可选工具，已有工具配置会继续使用。

Android 运行时内置 Purge 的第 40 和第 74 号补丁，分别用于在完整预设中保留注入段、
在组装聊天提示词前准备注入。两条补丁随本机引擎启动生效。其余宿主补丁保留“应用／撤销”流程。
运行环境升级会替换宿主目录，并保留已有 Purge 配置。

## CodeBuddy

1. 启动本机引擎，进入“设置 → 模型 → 添加渠道”。
2. 点击 **CodeBuddy**，粘贴自己的 CodeBuddy API Key，再点击“获取模型”。
3. 勾选模型并保存，在聊天里选择对应 CodeBuddy 渠道。
4. 更新已保存目录时，进入渠道详情点击“获取模型”，更新该渠道的模型配置与聊天选择器。

官方地址为 `https://www.codebuddy.cn/v2`。密钥沿用 Go 的凭据服务及 Android 安全存储，
不写进公开配置。界面的 OpenAI 协议用于渠道配置；实际生成由未修改的官方
Agent SDK 0.3.291／CLI 2.176.0 代理，工具交回 DSH 执行。
普通对话使用 SDK 自己的角色与精简的宿主工具说明，避开完整 DSH 提示词触发的 11128。
序列化历史明确要求继续处理当前用户请求，DSH 后附的运行时上下文或技能目录作为辅助信息。
选中「红队模式」或「无限制模式」时，聊天还会附加该预设的角色段和已启用的 Purge 注入段。
标题生成等显式任务保留自己的提示词。原生预设决定工具与技能，供应商决定是否回答具体请求。

每次获取目录都会创建新的官方 SDK 元数据会话，调用 `getAvailableModelsRaw()`，
此会话仅读取目录。每次获取都以 SDK 当次返回的数据为准。
模型名称、思考档位、视觉声明、上下文和输出上限经过发现、保存、回读进入真实调用；
选择的上下文长度也传给官方 CLI。官方 CodeBuddy 渠道中保存的 DeepSeek V4.1 Flash 旧版 30 万档，
运行时会同时为 DSH 和 CLI 解析为 100 万档。思考档位按服务声明提供，未选择时沿用服务默认。
视觉未知时不启用图片；缺少 token 上限、空目录或错误会让刷新失败，保留原目录。
目录可见不代表已验证账号能对所有模型进行生成。

CodeBuddy 返回上下文超限时，DSH 会尝试自动压缩并重试。摘要请求用兼容的提示词发送历史与摘要任务。
自动压缩和手动压缩统一由 DSH 管理，临时 CLI 会话的自动压缩关闭。
DSH 通常在目录所声明窗口的 80% 开始压缩，输出预留和安全余量也可能使触发点提前。
例如 Hy4 渠道声明 96 万时，默认 80% 触发点为 76.8 万。

缓存命中率按缓存读入量除以总输入量计算，输出不参与分母。
主聊天沿用 DSH 会话 ID 作为 CLI 会话标识。标题和摘要等辅助调用使用独立标识，可以并发运行。
适配器将 CLI 包含缓存的输入总量转换为 DSH 分开的未命中输入、缓存读入和缓存写入。
供应商报告缓存读入为零时显示零命中，工具回复和最终回复使用同一套统计。

## 验证边界

CI 安装固定依赖、应用 Go 补丁和本分支集成后运行回归。实际 SDK 对本机合成服务的
测试覆盖 DSH 写入／读取、长历史、图片、取消、继续发送与压缩传输，不产生付费调用。
Flutter 渠道测试覆盖能力保存和刷新失败保留旧目录。

开发时实际读取到当前账号的 15 个模型，并用默认 Purge 提示词完成了一次
DeepSeek V4.1 Flash 的 `OK` 回复。这不代表所有模型、Android 手机或 86 条宿主补丁
均已实测；手机安装与实际体验由所有者后续试用。
