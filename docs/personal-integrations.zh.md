[English](personal-integrations.md)

这是 ccch1mneyyy/dsh-Go 的独立个人分支，仅增加这两项集成，不是上游正式发行。
源码、署名与美术素材继续遵守各自原有条款。

## Purge Community

运行包固定安装 kingcharleslzy-ai/dsh-purge 的 MIT 许可版本 1.6.84，保留原始包、
提示词注入、预设、网页面板、状态检查和回滚入口；发行地址与 npm integrity 均固定。
在 Go 切换到官方网页版后使用 Purge 面板，网页插件发现也会列出这个包。

宿主补丁保留“应用／撤销”流程，安装本分支不会静默应用其 86 条宿主补丁。
应用后停止并重启本机引擎，核对真实状态；锚点漂移不能算成功。
运行环境升级会替换宿主目录，下次应用前应重新检查。已有 Purge 配置不被覆盖。

## CodeBuddy

1. 启动本机引擎，进入“设置 → 模型 → 添加渠道”。
2. 点击 **CodeBuddy**，粘贴自己的 CodeBuddy API Key，再点击“获取模型”。
3. 勾选模型并保存，在聊天里选择对应 CodeBuddy 渠道。
4. 更新已保存目录时，进入渠道详情点击“获取模型”，更新该渠道的模型配置与聊天选择器。

官方地址为 `https://www.codebuddy.cn/v2`。密钥沿用 Go 的凭据服务及 Android 安全存储，
不写进公开配置。界面的 OpenAI 协议用于渠道配置；实际生成由未修改的官方
Agent SDK 0.3.291／CLI 2.176.0 代理，工具交回 DSH 执行。
组合后的 DSH／Purge 提示词通过官方 SDK 的 append 选项传入。服务拒绝仍返回错误，
不伪造客户端身份，也不改写提示词规避拒绝。

每次获取目录都会创建新的官方 SDK 元数据会话，调用 `getAvailableModelsRaw()`，
此会话仅读取目录。每次获取都以 SDK 当次返回的数据为准。
模型名称、思考档位、视觉声明、上下文和输出上限经过发现、保存、回读进入真实调用；
选择的上下文长度也传给官方 CLI。思考档位按服务声明提供，未选择时沿用服务默认。
视觉未知时不启用图片；缺少 token 上限、空目录或错误会让刷新失败，保留原目录。
目录可见不代表已验证账号能对所有模型进行生成。

## 验证边界

CI 安装固定依赖、应用 Go 补丁和本分支集成后运行回归。实际 SDK 对本机合成服务的
测试覆盖 DSH 写入／读取、长历史、图片、取消、继续发送与压缩传输，不产生付费调用。
Flutter 渠道测试覆盖能力保存和刷新失败保留旧目录。

开发时实际读取到当前账号的 15 个模型，并用默认 Purge 提示词完成了一次
DeepSeek V4.1 Flash 的 `OK` 回复。这不代表所有模型、Android 手机或 86 条宿主补丁
均已实测；手机安装与实际体验由所有者后续试用。
